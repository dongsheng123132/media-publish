# 产品 / 工厂类文案撰写规则

> 面向**实体产品 / 工厂带货**的宣发（与软件类 `platform-copy-guidelines.md` 不同）。
> 软件类走开发者社区（HN/Reddit/掘金…），说「为什么做、技术细节、开源」；
> 产品类走**电商 + 消费社交**（Amazon/Alibaba/TikTok/小红书…），说「卖点、参数、信任背书、下单」。
> 生成 campaign 的 `title`/`text`/`fields` 时按对应平台规则写，可为每个字段挂多语言 `{en,zh,ja,es}`。

## 通用原则（产品类）

- **卖点前置**：第一行就是最强卖点 + 数字（15W / 3-in-1 / 折叠 / MOQ 500），不要铺垫。
- **信任背书**：认证（CE/FCC/RoHS/Qi2）、工厂年限、出货量、评分、退换政策——B2B/B2C 都吃这套。
- **关键词即流量**：Amazon/AliExpress/淘宝/Pinterest 靠搜索，标题/描述要塞**买家会搜的词**（型号、兼容机型、使用场景）。
- **一图胜千言**：产品类几乎每张卡都 `needsImage:true`，主图用产品实拍/渲染 hero 图。
- **诚实**：别标「最好/唯一/第一」这类绝对化用语（平台会限流/下架，广告法也管）。

## 海外 · B2B（批发 / 找分销）

### Amazon（B2C listing）— 关键词 + 五点描述
- **标题 ≤ 200 字符**：`品牌 + 品类 + 核心参数 + 兼容机型 + 关键卖点 + (颜色/规格)`。塞高频搜索词，别堆砌到读不通。
- **五点描述（bullet points）**：每条一个买点，大写开头短语引导（`FAST 15W CHARGING:` / `3-IN-1 DESIGN:`），先说利益再说参数。
- **描述 / A+**：场景化，讲「谁在什么场景用、解决什么」。
- **Search terms（后台关键词）**：填标题没覆盖的同义词/长尾，不重复、不带品牌。
- 各站点分语言：Amazon.com 英文 / Amazon.co.jp 日文 / Amazon.es 西文——别用机翻腔。

### Alibaba.com / Made-in-China（B2B 找分销商）
- 语气是「**供应商对采购**」：主打 **OEM/ODM、MOQ、认证、交期、产能、样品政策**。
- Product title：`品类 + 核心参数 + OEM/ODM + 关键词`（buyer 按关键词搜）。
- Key attributes：MOQ、Lead time、Certification、Customization（logo/包装/颜色）、Port、Payment（T/T、L/C）。
- 首次询盘回复模板（inquiry reply）：报 MOQ 阶梯价、样品费、交期、认证附件——**准备好一段可复制的回复**。

### 1688 · 批发（国内分销 / 一件代发）
- 主打**厂家直销、支持一件代发、阶梯价、现货**。标题塞「工厂直销/源头厂家/一件代发/支持定制」。
- 详情讲清起订量、发货时效、售后，配实拍图与质检细节。

### AliExpress / Temu（跨境 B2C 平价）
- 标题关键词 + 兼容机型 + 卖点；变体（颜色/规格）讲清。
- 强调**价格力、免运费、评分、快速物流**；Temu 尤其吃「低价 + 清晰主图」。

## 海外 · 消费社交（种草 / 引流）

### TikTok — 3 秒钩子 + 使用场景
- 前 3 秒必须出钩子（痛点/反差/结果）。文案极短，靠视频演示（开箱、一充三设备、折叠收纳）。
- 加 3-5 个精准标签（`#techtok #gadgets #wirelesscharger`）。挂小黄车/主页链接引导下单。

### Instagram — 生活方式 + Reels
- 首图/首帧是氛围产品图（桌面/床头/旅行场景）。文案讲 lifestyle 利益，末尾 CTA + 标签（首条评论放长标签串）。

### YouTube Shorts — 竖版演示
- 标题 ≤ 100 字，hook + 数字。竖版 15-30s 演示一充三设备/折叠。

### Pinterest — 关键词描述 + 竖图
- **描述塞搜索关键词**（Pinterest 是搜索引擎）：使用场景、机型、风格词（`minimalist desk setup`）。竖图 2:3。可用 `pin/create/button` 预填 url+description。

### Facebook — 社群 / Marketplace
- 语气生活化，讲「解决了什么麻烦」。可发主页/群组/Marketplace。`sharer.php?u=` 只能预填链接，文案手动粘。

### WhatsApp — 直接分享给客户/群
- 一句话卖点 + 链接，`wa.me/?text=` 预填。适合把新品直接推给老客户/分销群。

### LinkedIn（B2B 品牌）
- 面向采购/经销商：讲产能、认证、案例、展会。前 2 行黄金位放最硬的信任点。

## 国内 · 电商 + 消费社交

### 淘宝 / 天猫 — 标题关键词 + 详情页
- **标题 ≤ 30 字**，塞高频搜索词（品类+参数+兼容+卖点+人群）。详情页图文讲场景、参数、质检、售后。

### 拼多多 — 价格力 + 主图
- 突出**低价、百亿补贴、拼团**；主图第一屏说清卖点，短平快。

### 小红书 — 种草、口语、emoji
- 共鸣式开头（「桌面一堆线好烦😩」）。emoji 小标题 + ✅清单 + before/after。单独一行放 tags。必须配图/短视频。

### 抖音 / 快手 — 短视频带货
- 标题钩子 + 数字，正文极短。演示「一个底座充满手机+手表+耳机」「折叠塞进口袋」。挂小黄车。

### 微博 — 一句话 + 话题
- 一句话卖点 + #话题#，配图。可用 `service.weibo.com/share` 预填。

### 视频号 — 配视频、私域
- 标题 ≤ 30 字 hook。适合私域/直播预告导流。

## 多语言注意

- **别机翻**：Amazon/独立站文案母语撰写，日文避免生硬直译、西文注意 tú/usted 语气与地区用词。
- 同一 campaign 里，全球平台建议至少 `en`；进日本市场加 `ja`，进拉美/西班牙加 `es`，国内平台用 `zh`。
- 引擎按 `campaign.langs` 顺序展示语言下拉；某字段缺某语言时回退到 `defaultLang`。
